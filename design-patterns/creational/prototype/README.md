# Прототип (Prototype)

**Тип:** породжуючий патерн.

## Опис
Дозволяє створювати нові об'єкти **копіюванням наявних** (прототипів), не залежачи від їхніх конкретних класів. Об'єкт сам вміє себе клонувати.

## Яку проблему вирішує
Коли створення об'єкта «з нуля» дороге або складне, а потрібні лише невеликі зміни вже готового зразка. Також корисний, коли клас невідомий на етапі компіляції.

## Приклад у коді
- `Document` реалізує `clone()` через `copy.deepcopy`, тому копія незалежна від оригіналу.
- `PrototypeRegistry` зберігає готові шаблони й видає їхні клони.

## Запуск

python main.py
