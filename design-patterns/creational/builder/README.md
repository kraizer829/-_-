# Будівельник (Builder)

**Тип:** породжуючий патерн.

## Опис
Відокремлює конструювання складного об'єкта від його подання, дозволяючи створювати його **покроково** і отримувати різні варіанти одного й того самого об'єкта.

## Яку проблему вирішує
Уникає «телескопічних конструкторів» з десятком параметрів, коли більшість із них необов'язкові. Код створення стає читабельним завдяки ланцюжку викликів.

## Приклад у коді
- `Computer` — складний продукт.
- `ComputerBuilder` — будівельник із методами `set_cpu`, `set_ram`, `set_storage`, `set_gpu`, `build`.
- `Director` — знає готові конфігурації (`office_pc`, `gaming_pc`).

## Запуск
```bash
python main.py
```
