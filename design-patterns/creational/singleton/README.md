# Одинак (Singleton)

**Тип:** породжуючий патерн.

## Опис
Гарантує, що в класу є **лише один екземпляр**, і надає до нього глобальну точку доступу.

## Яку проблему вирішує
Потрібен єдиний спільний ресурс: конфігурація, логер, пул з'єднань. Кілька копій призвели б до неузгодженості даних.

## Приклад у коді
`AppConfig` перевизначає `__new__` так, що всі виклики `AppConfig()` повертають один і той самий об'єкт. Блокування `threading.Lock` із подвійною перевіркою робить створення безпечним у багатопоточному середовищі.

## Зауваження
Singleton ускладнює тестування й по суті є глобальним станом, тому використовувати його варто обережно.

## Запуск
```bash
python main.py
```
