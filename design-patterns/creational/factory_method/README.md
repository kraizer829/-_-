# Фабричний метод (Factory Method)

**Тип:** породжуючий патерн.

## Опис
Визначає загальний інтерфейс для створення об'єктів у базовому класі, але дозволяє підкласам самим вирішувати, об'єкт якого класу створювати. Клієнтський код працює з абстракцією `Transport` і не залежить від конкретних класів.

## Яку проблему вирішує
Коли код не знає заздалегідь, об'єкти яких класів йому доведеться створювати, або коли потрібно легко додавати нові типи продуктів без зміни наявного коду.

## Приклад у коді
- `Transport` — інтерфейс продукту, `Truck` і `Ship` — конкретні продукти.
- `Logistics` — творець із фабричним методом `create_transport()`.
- `RoadLogistics` створює `Truck`, `SeaLogistics` — `Ship`.

## Запуск
```bash
python main.py
```
