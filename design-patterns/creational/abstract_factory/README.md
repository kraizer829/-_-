# Абстрактна фабрика (Abstract Factory)

**Тип:** породжуючий патерн.

## Опис
Надає інтерфейс для створення **сімейств взаємопов'язаних об'єктів** без вказівки їхніх конкретних класів. Кожна конкретна фабрика випускає продукти одного «стилю», тому вони гарантовано сумісні між собою.

## Яку проблему вирішує
Коли програма має працювати з різними наборами пов'язаних об'єктів (наприклад, елементи інтерфейсу для різних ОС) і не можна змішувати об'єкти з різних наборів.

## Приклад у коді
- `Button` і `Checkbox` — абстрактні продукти.
- `WindowsButton/WindowsCheckbox` та `MacButton/MacCheckbox` — конкретні продукти двох сімейств.
- `GUIFactory` — абстрактна фабрика, `WindowsFactory` і `MacFactory` — її реалізації.
- Функція `build_form` працює лише з абстракціями.

## Запуск
```bash
python main.py
```
