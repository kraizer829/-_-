# Адаптер (Adapter)

**Тип:** структурний патерн.

## Опис
Перетворює інтерфейс одного класу на інтерфейс, якого очікує клієнт. Дозволяє працювати разом класам із несумісними інтерфейсами.

## Яку проблему вирішує
Потрібно використати наявний (часто сторонній) клас, але його інтерфейс не збігається з тим, що очікує ваш код, а змінити його не можна.

## Приклад у коді
- `PaymentProcessor` — інтерфейс, який очікує застосунок (`pay(amount_uah)`).
- `ForeignGateway` — сторонній сервіс з іншим методом `make_transaction(cents, currency)`.
- `ForeignGatewayAdapter` переводить гривні в копійки й викликає потрібний метод.

## Запуск
```bash
python main.py
```
