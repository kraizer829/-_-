# Легковаговик (Flyweight)

**Тип:** структурний патерн.

## Опис
Економить пам'ять, **розподіляючи спільні частини стану** між багатьма об'єктами замість зберігання однакових даних у кожному з них.

## Яку проблему вирішує
Коли потрібно створити величезну кількість схожих об'єктів і вони не вміщуються в пам'ять. Стан ділиться на:
- **внутрішній** (спільний, незмінний) — зберігається в легковаговику;
- **зовнішній** (унікальний) — зберігається в контексті або передається ззовні.

## Приклад у коді
- `TreeType` — легковаговик (назва, колір, текстура).
- `TreeFactory` — кеш, що повертає вже створений `TreeType`.
- `Tree` — зберігає лише координати та посилання на тип. У лісі 2000 дерев, але лише 2 об'єкти `TreeType`.

## Запуск
```bash
python main.py
```
