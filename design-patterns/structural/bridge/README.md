# Міст (Bridge)

**Тип:** структурний патерн.

## Опис
Розділяє **абстракцію** та її **реалізацію** на дві незалежні ієрархії, які можна розвивати окремо. Зв'язок між ними здійснюється через композицію (поле з посиланням на реалізацію).

## Яку проблему вирішує
Без мосту кількість класів зростає комбінаторно (кожен пульт × кожен пристрій). З мостом нові пульти й нові пристрої додаються незалежно.

## Приклад у коді
- Реалізація: `Device`, `TV`, `Radio`.
- Абстракція: `RemoteControl`, `AdvancedRemote`, що містить посилання `device`.

## Запуск
```bash
python main.py
```
