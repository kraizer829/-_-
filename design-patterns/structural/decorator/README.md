# Декоратор (Decorator)

**Тип:** структурний патерн.

## Опис
Динамічно додає об'єктам нову поведінку, «обгортаючи» їх у класи-декоратори з тим самим інтерфейсом. Це гнучка альтернатива наслідуванню.

## Яку проблему вирішує
Без декораторів для кожної комбінації добавок довелося б створювати окремий підклас (`CoffeeWithMilkAndSugar` тощо). Декоратори комбінуються в довільному порядку під час виконання.

## Приклад у коді
- `Coffee` — спільний інтерфейс, `Espresso` — базовий компонент.
- `Milk`, `Sugar`, `Syrup` — декоратори, що збільшують ціну й доповнюють опис.

## Запуск
```bash
python main.py
```
