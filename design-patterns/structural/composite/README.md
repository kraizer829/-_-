# Компонувальник (Composite)

**Тип:** структурний патерн.

## Опис
Об'єднує об'єкти в **деревоподібну структуру** і дозволяє працювати з окремими об'єктами та їхніми групами однаково, через спільний інтерфейс.

## Яку проблему вирішує
Коли програма працює з ієрархіями «частина — ціле» (файли й папки, меню, графічні фігури) і клієнт не повинен розрізняти простий елемент і контейнер.

## Приклад у коді
- `FileSystemItem` — спільний інтерфейс (`size`, `show`).
- `File` — листок, `Folder` — контейнер, який рекурсивно делегує роботу дочірнім елементам.

## Запуск
```bash
python main.py
```
