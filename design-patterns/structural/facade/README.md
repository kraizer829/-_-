# Фасад (Facade)

**Тип:** структурний патерн.

## Опис
Надає **простий уніфікований інтерфейс** до складної підсистеми (набору класів, бібліотеки, фреймворку).

## Яку проблему вирішує
Клієнту не потрібно знати про десятки класів підсистеми й порядок їхніх викликів. Фасад ховає складність і зменшує зв'язність між клієнтом та підсистемою.

## Приклад у коді
`HomeTheaterFacade` має два прості методи `watch_movie()` і `end_movie()`, які самі керують світлом, проєктором, звуком і програвачем.

## Запуск
```bash
python main.py
```
