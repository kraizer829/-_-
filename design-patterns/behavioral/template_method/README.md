# Шаблонний метод (Template Method)

**Тип:** поведінковий патерн.

## Опис
Задає **скелет алгоритму** в базовому класі, а окремі кроки віддає підкласам. Підкласи можуть перевизначати кроки, не змінюючи загальної структури алгоритму.

## Яку проблему вирішує
Усуває дублювання коду в схожих алгоритмах, де відрізняються лише деякі етапи.

## Приклад у коді
- `DataProcessor.process()` — шаблонний метод: `read → parse → analyze → (report)`.
- `read` і `parse` абстрактні, їх реалізують `CsvProcessor` та `TextProcessor`.
- `needs_report` — «хук» із поведінкою за замовчуванням, який може перевизначити підклас.

## Запуск
```bash
python main.py
```
