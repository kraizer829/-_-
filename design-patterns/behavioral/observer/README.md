# Спостерігач (Observer)

**Тип:** поведінковий патерн.

## Опис
Визначає залежність «один до багатьох»: коли стан одного об'єкта (суб'єкта) змінюється, усі підписані на нього об'єкти (спостерігачі) автоматично отримують сповіщення.

## Яку проблему вирішує
Об'єктам потрібно реагувати на зміни іншого об'єкта, але вони не повинні бути жорстко з ним зв'язані. Підписників можна додавати й прибирати під час виконання (події в GUI, розсилки, реактивні системи).

## Приклад у коді
- `ExchangeRates` — суб'єкт із `subscribe`, `unsubscribe` і `set_rate`.
- `MobileApp` та `EmailSubscriber` — спостерігачі, що реалізують `update()`.
