# Ланцюжок обов'язків (Chain of Responsibility)

**Тип:** поведінковий патерн.

## Опис
Передає запит по ланцюжку обробників. Кожен обробник сам вирішує, чи обробити запит, чи передати його далі.

## Яку проблему вирішує
Відправник не прив'язаний до конкретного отримувача, а склад і порядок обробників можна змінювати динамічно. Типові приклади: middleware у веб-серверах, ескалація в службі підтримки, фільтри.

## Приклад у коді
`Bot → Operator → Manager`: запит рівня 1 обробляє бот, рівня 2 — оператор, рівня 3 — менеджер. Якщо ніхто не підійшов, повертається повідомлення про необроблений запит.

## Запуск
```bash
python main.py
```
