# Посередник (Mediator)

**Тип:** поведінковий патерн.

## Опис
Зменшує безладні зв'язки між об'єктами: вони більше не звертаються один до одного напряму, а спілкуються **через об'єкт-посередник**.

## Яку проблему вирішує
Коли багато об'єктів тісно пов'язані «кожен з кожним», систему важко змінювати й тестувати. Посередник централізує логіку взаємодії (приклади: чати, диспетчер в аеропорту, діалогові вікна з залежними полями).

## Приклад у коді
- `ChatRoom` — посередник, який розсилає повідомлення.
- `User` знає лише про кімнату, а не про інших користувачів.

python main.py
