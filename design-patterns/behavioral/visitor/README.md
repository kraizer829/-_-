# Відвідувач (Visitor)

**Тип:** поведінковий патерн.

## Опис
Дозволяє додавати нові операції до ієрархії класів, **не змінюючи самі класи**. Операція виноситься в окремий клас-відвідувач, а елементи лише «приймають» його через метод `accept()` (подвійна диспетчеризація).

## Яку проблему вирішує
Коли до набору різнорідних об'єктів потрібно додавати все нові й нові операції (розрахунки, експорт, валідація), а змінювати самі класи не хочеться.

## Приклад у коді
- Елементи: `Circle`, `Rectangle` з методом `accept(visitor)`.
- Відвідувачі: `AreaVisitor` (площа) та `JsonExportVisitor` (експорт у JSON).

## Запуск
```bash
python main.py
```
