# Стан (State)

**Тип:** поведінковий патерн.

## Опис
Дозволяє об'єкту змінювати свою поведінку залежно від внутрішнього стану. Зовні це виглядає так, ніби змінився клас об'єкта.

## Яку проблему вирішує
Замість величезних конструкцій `if/elif` за значенням поля «статус» кожен стан виноситься в окремий клас зі своєю логікою переходів.

## Приклад у коді
`Order` делегує дії поточному стану: `NewState → PaidState → ShippedState → DeliveredState`, а також `CancelledState`. Кожен стан сам вирішує, що дозволено (наприклад, відправлене замовлення скасувати не можна).

## Запуск

python main.py
