# Стратегія (Strategy)

**Тип:** поведінковий патерн.

## Опис
Визначає сімейство взаємозамінних алгоритмів, інкапсулює кожен з них в окремий клас і дозволяє **підміняти алгоритм під час виконання**.

## Яку проблему вирішує
Уникає розгалужених умов `if/elif` для вибору алгоритму. Нові алгоритми додаються без зміни клієнтського коду (принцип відкритості/закритості).

## Приклад у коді
- `DeliveryStrategy` — спільний інтерфейс.
- `CourierDelivery`, `PostDelivery`, `PickupDelivery` — конкретні стратегії.
- `Order` використовує обрану стратегію та може змінити її через `set_strategy()`.

## Запуск
```bash
python main.py
```
