# Команда (Command)

**Тип:** поведінковий патерн.

## Опис
Перетворює запит (дію) на окремий об'єкт, що містить усю інформацію про цю дію. Завдяки цьому дії можна передавати як аргументи, ставити в чергу, логувати та **скасовувати**.

## Яку проблему вирішує
Розділяє того, хто ініціює дію (кнопка, меню), і того, хто її виконує. Дає змогу реалізувати undo/redo, черги завдань і макрокоманди.

## Приклад у коді
- `Command` — інтерфейс з `execute()` і `undo()`.
- `AppendCommand`, `UppercaseCommand` — конкретні команди над `Editor` (отримувач).
- `Invoker` виконує команди й зберігає історію для скасування.

## Запуск
```bash
python main.py
```
