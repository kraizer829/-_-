# Ітератор (Iterator)

**Тип:** поведінковий патерн.

## Опис
Надає спосіб послідовного доступу до елементів колекції **без розкриття її внутрішньої структури**.

## Яку проблему вирішує
Колекції можуть бути списками, деревами, графами. Ітератор виносить логіку обходу в окремий об'єкт, і клієнт використовує однаковий інтерфейс для будь-якої колекції. Можна мати кілька способів обходу одночасно.

## Приклад у коді
- `BookShelf` — колекція; `__iter__` повертає прямий ітератор, `reversed()` — зворотний.
- `ForwardIterator` і `ReverseIterator` реалізують протокол Python (`__iter__`, `__next__`), тому працюють у циклі `for`.
