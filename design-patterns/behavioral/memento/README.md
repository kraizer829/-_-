# Знімок (Memento)

**Тип:** поведінковий патерн.

## Опис
Дозволяє зберегти й пізніше відновити попередній стан об'єкта, **не порушуючи його інкапсуляції**.

## Яку проблему вирішує
Потрібна функція «скасувати» або контрольні точки, але розкривати внутрішню структуру об'єкта назовні небажано.

## Приклад у коді
Три ролі патерну:
- `TextEditor` (творець) створює `Memento` зі своїм станом і відновлюється з нього;
- `Memento` — незмінний знімок (`frozen dataclass`);
- `History` (опікун) зберігає знімки, не знаючи їхнього вмісту.

## Запуск
```bash
python main.py
```
